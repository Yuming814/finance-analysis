\# 个人记账数据综合分析



\## 项目简介

基于一年个人记账数据，分析收支结构、消费习惯和结余情况，并生成可视化报告。



\## 数据来源

模拟生成的一年记账数据（约 700+ 条记录），字段包括日期、类型、类别、金额、备注。



\## 分析流程

1\. 加载数据，转换日期类型

2\. 派生年、月、星期字段

3\. 拆分收入与支出

4\. 可视化分析：月度趋势、类别占比、堆叠图、金额分布、周末对比、结余、Top 支出、类别趋势、收入来源



\## 主要发现

\- 房租是最大支出项

\- 餐饮和购物波动最大

\- 周末消费高于工作日

\- 大部分月份有结余

\- 收入结构以工资为主
